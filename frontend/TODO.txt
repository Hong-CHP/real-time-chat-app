  1. Blog functionality
     You do not have blog models in backend/prisma/schema.prisma:15. There are only User, Room, Message, and Friend.

     Add:
      - Post model.
      - Comment model if readers can comment.
      - Optional Tag / Category.
      - Optional Like / reaction model.
      - Backend CRUD routes for posts.
      - Frontend pages: blog home, post detail, create/edit post.
  2. Real home/blog page
     Your home page is only a login link in frontend/src/pages/Home.tsx:3.

     You probably need:
      - Blog post list.
      - About section.
      - Navigation to blog/chat/profile.
      - Public view for visitors.
  3. Post editor
     Missing completely.

     You need a page where you can:
      - Create a blog post.
      - Edit a blog post.
      - Delete a blog post.
      - Save title, content, image, created date, author.
  4. Profile features
     Backend supports GET /users/me, PATCH /users/me, and DELETE /users/me in backend/src/users/
  users.controller.ts:35, but the frontend profile page only displays email and id in frontend/src/pages/
  Profile.tsx:37.

     Add:
      - Edit username/email/password UI.
      - Delete account UI.
      - Show username, not only email/id.
  5. Group chat UI
     Backend has room creation in backend/src/room/room.controller.ts:23, but I don’t see frontend UI to create group
  rooms.

     Add:
      - Create group chat.
      - Add selected friends to group.
      - Show group members.
  6. Friend management
     You can send, accept, refuse, list, and block friends. But frontend is missing:
      - Cancel sent friend request.
      - Remove friend.
      - Block/unblock UI.
      - Show pending sent requests.
      - Better feedback after sending request.
  7. Chat polish
     Current chat works, but you still need:
      - Prevent sending empty messages.
      - Auto-scroll to latest message.
      - Show sender name/time.
      - Better error display instead of alert.
      - Refresh room list after new messages.
      - Show online/offline users.
      - Maybe typing indicator.
  8. Validation and security
     DTO validation is very light. For example CreateUserDto has no validators.

     Add:
      - @IsEmail, @IsString, @MinLength, etc.
      - Message length validation.
      - Post title/content validation.
      - Production-safe cookie settings.
      - More restricted WebSocket CORS. Right now it uses origin: '*' in backend/src/chat/chat.gateway.ts:18.
  9. Tests
     You have some spec files, but the main app flows need real tests:
      - Register/login.
      - Create/read/update/delete blog post.
      - Send friend request.
      - Accept friend request creates private room.
      - Send/get messages.

  Recommended order

  1. Build blog database models.
  2. Add blog backend routes/services.
  3. Build blog pages on frontend.
  4. Improve profile page.
  5. Add group chat creation UI.
  6. Polish chat/friend UX.
  7. Add validation and tests.
